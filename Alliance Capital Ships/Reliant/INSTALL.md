# Installation

Use your own installed StarLancer data with official OpenReliant 0.18.0. Copy `mods/119-reliant-worn-v1` into the game's `mods` folder beside `resource.hog`, replacing the previous Reliant copy. Enable the mod and restart.

Choose one texture resolution for the Reliant; do not install tiers side by side. Keep personal pilot saves. Enable MATERIALS, PER-PIXEL LIGHTING and MOD EFFECTS; BLOOM adds a halo.

The pack works with the original Patriot. The flight launcher also enables the separate Patriot exterior/cockpit packs if they are installed. They are optional and are not bundled here.

Linux: run one of the included `tools/launch-reliant-*.sh` launchers. They use `OPENRELIANT_HOME` or `~/Games/OpenReliant`. Other systems can load mission 959 (inspection), 958 (doors), or 957 (Patriot launch/landing) using the official engine's mission option.
