# Galahad - Worn Paint

**Artwork 1.1 approved for this beta.** Package **0.1.0-beta.1**, targeting official OpenReliant 0.8.1.

Restores the worn grey Alliance torpedo bomber with corrected silver RAF birds matching Crusader, inset green glazing, finer cockpit wear and structural normal/roughness/metallic maps. One canonical PNG material set; the engine generates loadout colours.

The native six-part BTB_Glhd model retains its geometry, normals, UV coordinates, attachments and animations. Six strip/fan continuation counts were corrected across 1,012 native faces so the original texture joins are respected. The four animated feet and the body's two torpedo mounts remain separate native mechanisms. Review launchers cover stowed, deployed, cycling and timed two-torpedo release states.

Artwork accepted by the user after the cockpit cleanup and reflection-mask revision. Official 0.8.1 native-format, material-loader, portable-source and installed/package hash checks passed. This does not establish full campaign, deployment/release sequence, damage or platform coverage.
