# Remaining work

- Artwork 1.1 is accepted for this beta round. Further refinements can follow user feedback.
- The native deploy/reverse and two-torpedo release missions are supplied and structurally validated; their full sequences still need explicit gameplay verification.
- Campaign combat, damage, ejection, cloaking, distance transitions and other platforms are untested.
- Dedicated emissive maps remain deferred.
- The 4096-square base atlas is derived from a 1254-square reconstruction of the 256-square original. The cockpit wear uses a separate higher-detail generated patch; this is not entirely native 4K generation.
- The gallery still is a labelled Blender preview. The default is the native 3D model; an in-game gallery photo is pending.
