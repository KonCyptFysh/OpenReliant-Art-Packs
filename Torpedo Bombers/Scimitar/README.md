# Scimitar - Worn Paint

**Artwork 1.0 approved for this beta.** Package **0.1.0-beta.1**. Native compatibility baseline OpenReliant 0.8.1; supplied review launchers use official 0.18.0.

Restores worn grey and brown armour, red accents, caution markings and machinery. Includes inset amber glazing, independent frame relief and restrained structural normal, roughness and metallic maps. One canonical PNG material set supports engine-generated loadout colours.

The native model retains its geometry, UV coordinates, normals, attachments and static animation clip. All 476 triangles were audited; 13 primitive continuation counts were corrected at incompatible UV joins. One shared model serves player and AI uses. Two fixed torpedo launch mounts are preserved; the original has no deployment motion.

Artwork accepted by the user for this beta round. Native checks passed on official 0.8.1 and 0.18.0; map, loadout-colour, portable-source and package checks passed. Full campaign and timed-release coverage remain unverified.
