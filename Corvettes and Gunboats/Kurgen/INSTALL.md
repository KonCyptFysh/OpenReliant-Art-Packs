# Install and inspect

Requires official OpenReliant 0.18.0. Copy `mods/116-kurgen-worn-v1` to your game-data mods folder and restart the game. Enable MATERIALS, PER-PIXEL LIGHTING and MOD EFFECTS; BLOOM adds halos.

The response runs on player and AI Kurgens in ordinary missions. Test controls and artificial damage are restricted to mission 962.

Developer inspection missions and launchers are retained in the local authoring workspace; use the named release ZIP for player installation.
