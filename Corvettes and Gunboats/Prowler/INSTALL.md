# Installation

Copy mods/117-prowler-worn-v1 into your OpenReliant game-data/mods folder, replacing this pack's previous copy. Enable the mod and restart the game. Requires official 0.18.0, MATERIALS, PER-PIXEL LIGHTING and MOD EFFECTS; BLOOM adds a halo.

Run tools/launch-prowler-test.sh for mission 961. Press F5 for thrust, F6/F7 for review damage, F8 to restore, F9 for engine-disable. Press 7 for orbit; arrows rotate and Shift+Up/Down zoom. See LIGHTING.md.

Select one resolution per ship. Do not install multiple resolution tiers side by side.
