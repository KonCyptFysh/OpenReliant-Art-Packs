# Prowler - Worn Paint

**Approved beta 0.1.0-beta.1, artwork revision 1.2. Requires OpenReliant 0.18.0.**

Restored worn Alliance escort corvette with structural normal and material maps, subdued green glazing, and a black-outlined, chipped AL-47 stencil. The original hull detailing, native geometry and four shared Alliance turrets are retained.

Cabin lighting dims with damage. Significant hits cause brief interruptions; at or below 30% health, irregular power faults jump through absolute 0–100% brightness, including blackouts and full-brightness surges. Engine illumination follows thrust, while recessed nozzle interiors retain heat and cool gradually. The misplaced legacy stern light is disabled, and the nozzle mask has been corrected to remove triangular gaps.

**Planned refinement:** Refine the window lighting in a later artwork pass. The current appearance and full-range damage response are accepted for this beta.

Choose one of the 1K, 2K or 4K downloads; all use the same lighting behaviour. Replace this ship's existing mod folder when changing resolution. Runtime materials are one canonical PNG set, without redundant green/red copies.

The included `tools/launch-prowler-test.sh` opens a quiet review mission. F5 cycles thrust, F6/F7 apply small/heavy hits, F8 restores armour and F9 disables engines. See [LIGHTING.md](LIGHTING.md) and [KNOWN_ISSUES.md](KNOWN_ISSUES.md).

The user approved this beta. 43 response checks, official 0.18.0 integration, all-detail nozzle-mask checks and native/material validation pass. The gallery uses a fresh official-engine photograph. The rotatable browser model is a static viewing copy.
