# Installing Recommissioned HUD

HUD 1.10 requires OpenReliant 0.9.0 or later, configured with your StarLancer game data.

Drop the complete HUD `.hog` file into OpenReliant's `mods` folder. When updating,
replace the previous HUD pack as a whole. Enable Recommissioned HUD in
GAME OPTIONS → MODS and restart. Keep only one copy of this HUD enabled.

The pack already contains all 257 finished HD portrait videos, the artwork,
fonts and ready-to-run HUD script. Players do not need to build or convert
anything, replace individual portraits, or edit shaders. Mod Effects may be
on or off; the HUD no longer needs a shader override.

This Git snapshot contains HUD 1.10. The existing beta.1 download is still
HUD 1.8 for OpenReliant 0.8.1; no new player download accompanies this Git update.
The GitHub source-code archive is for modders, not a player package. Export and
source checkout instructions belong to [the maintainer workflow](WORKFLOW.md).

The maintainer accepted this working update for Git publication. Extensive
playtesting remains; see [known issues](KNOWN_ISSUES.md) for current limitations.
