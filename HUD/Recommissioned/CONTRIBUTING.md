# Reporting problems and contributing

Please check KNOWN_ISSUES.md and the existing GitHub issues first. Use the bug form for broken behaviour and the artwork form for an unfinished asset or improvement. Give the mod version, exact OpenReliant build, operating system, resolution, mission, ship, reproduction steps and screenshots. Include other enabled mods and load order.

For art changes, identify the source and the affected runtime files. Preserve accepted geometry, UVs, colours, transparency and worn appearance unless the change explicitly addresses them. Keep the editable source available, update the asset inventory and describe what was checked in game. Do not include game archives, saves, caches or unrelated working files.

Use a focused branch and pull request for a change. Update the changelog and close a tracked item only when its acceptance checks are met. Reusing a source file's existing licence does not imply that unrelated artwork has that licence.
