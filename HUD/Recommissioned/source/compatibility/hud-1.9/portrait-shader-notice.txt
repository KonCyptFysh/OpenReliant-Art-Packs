Working candidate; public release held. Tested with the unmodified engine
build above. Enable MOD EFFECTS and restart the game when installing.
Only one mod can replace device.glsl; another replacement can override it.
The renderer shader interface may change even while the mod API is frozen.
If this shader is disabled, rejected or overwritten, the HD films will be
oversized. For native portraits, remove device.glsl and ALL 225 FM8 files
listed in the pack inventory together, or restore the previous HUD backup.
The API still reports raw film bounds; the correction is visual.
