# Authoring history

The packed `../basilisk_worn_pbr_v4.blend` is the current approved editable source. Earlier recipes and reports are preserved as history; do not rerun them over an edited scene. Original machine-local copies remain in the canonical authoring workspace.

To adapt a recipe, set BASILISK_WORKSPACE to a separate writable ship workspace, ART_PACK_REPOSITORY to this repository, OPENRELIANT_HOME to a test installation and OPENRELIANT_SLTOOL to its official 0.7.0 tool. Reconstruct the historical workspace layout using originals, maps and the corresponding authoring pass. Blender recipes need Blender; export checks also use NumPy and Pillow. Environment placeholders in historical reports identify their former local paths. Local installation helpers and runtime logs are excluded.

Current approval, release and validation records are at the asset root.
