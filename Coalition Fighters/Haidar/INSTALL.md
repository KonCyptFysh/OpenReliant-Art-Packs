# Installation and inspection

Copy `mods/111-haidar-worn-v1` into OpenReliant's `game-data/mods` directory and enable the mod. Keep all runtime files flat. Requires your own StarLancer installation and official OpenReliant 0.8.1.

Press 7 for orbit view, arrow keys to rotate, Shift+Up/Down to zoom and 0 to save an in-game screenshot. Additional engine options can be passed to the launcher. Remove or disable the mod to restore the original Haidar.

No green/red texture duplicates are required. OpenReliant generates loadout colours from the unprefixed material set.

Developer inspection missions and launchers are retained in the local authoring workspace; use the named release ZIP for player installation.
