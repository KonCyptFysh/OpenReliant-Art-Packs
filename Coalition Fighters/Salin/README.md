# Salin - Worn Paint

User-approved worn artwork **1.0**, packaged as **0.1.0-beta.1** for **OpenReliant 0.8.1**, under Coalition Fighters.

Restores the original silver-grey panels, red-and-gold stars and stripes, warning triangles and hazard stripes and amber glazing. Structural normal, roughness and metallic maps add recessed window edges, bounded radiator relief and panel seams. Glass interiors have flat normals and a smooth reflective response. One unprefixed PNG material set is shared with engine-generated loadout colours.

All original UV coordinates are retained. Native fan/strip continuity was checked across all 898 faces in 7 detail meshes; 44 continuation counts were corrected to retain the intended UVs. Geometry, normals, winding, parts, attachments and animation records remain unchanged. The Blender source is a static authoring pose; the native game export preserves the original animation.

The user accepted the first pass without revisions. Official 0.8.1 native round-trip and texture-loader checks passed, along with portable source and installed-file checks. The gallery uses four actual in-game user captures, including rear, underside and firing views. Broader gameplay, damage and distance transitions remain outside the completed review.
