# Saracen - Worn Paint

User-approved worn artwork **1.0**, packaged as **0.1.0-beta.1** for **OpenReliant 0.8.1**, under Coalition Fighters.

Restores the original grey alloy and bronze-brown panels, red warning triangles, hazard stripes and green glazing. Structural normal, roughness and metallic maps add recessed window edges, bounded radiator relief and panel seams. Glass interiors have flat normals and a smooth reflective response. One unprefixed PNG material set is shared with engine-generated loadout colours.

Two collapsed finest-detail wing-edge UV triangles were corrected with their adjacent faces, giving four continuously mapped faces on a plain alloy strip. Original UV layers remain in the editable scene; all lower-detail UV coordinates are retained. Native fan/strip continuity was checked across all 1,918 faces in 14 detail meshes; 145 continuation counts were corrected to retain the intended UVs. Geometry, normals, winding, parts, attachments and animation records remain unchanged. The Blender source is a static authoring pose; the native game export preserves the original animation.

The user accepted the first pass without revisions. Official 0.8.1 native round-trip and texture-loader checks passed, along with portable source and installed-file checks. The gallery uses four actual in-game user captures, including firing, underside and rear views. Broader gameplay, damage and distance transitions remain outside the completed review.
