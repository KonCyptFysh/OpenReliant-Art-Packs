# Installation and inspection

Copy `mods/110-saracen-worn-v1` into OpenReliant's `game-data/mods` directory and enable the mod. Keep all runtime files flat. Requires your own StarLancer installation and official OpenReliant 0.8.1.

Place `tools/launch-saracen-test.sh` alongside `launch-openreliant.sh`, or set OPENRELIANT_HOME to your installation. This opens mission 976 as the Saracen (ship type 46), with one ship, no enemies or objectives. The launcher uses official 0.8.1 directly, sound disabled, 1920x1080 and a 60 FPS limit.

Press 7 for orbit view, arrow keys to rotate, Shift+Up/Down to zoom and 0 to save an in-game screenshot. Additional engine options can be passed to the launcher. Remove or disable the mod to restore the original Saracen.

No green/red texture duplicates are required. OpenReliant generates loadout colours from the unprefixed material set.
