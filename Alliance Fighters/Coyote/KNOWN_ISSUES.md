All native models/missions and the PNG loadout-colour pipeline passed non-visual checks. No new 0.8.1 gameplay or GPU-rendering capture was performed. - Full campaign play, damage, ejection, loadout, Shroud cloak, distance transitions, Windows and macOS need broader testing: [#6](https://github.com/KonCyptFysh/OpenReliant-Art-Packs/issues/6).

This is a bounded Linux rendering beta, not a full gameplay certification. Exact checks and file hashes are in `validation.json`.
