# Patriot editable source

Open `patriot_worn_audit_v3.blend`. Images are packed and also provided through relative `resources/` paths. The native three-part geometry, turret, custom corner normals, hidden damage caps and all earlier UV layers are preserved. Original reconstruction maps and masks remain available.

The latest pass adjusts 44 body triangles: six full-span shoulder-grille fins, brighter forward radiator fins, continuous outer-engine panels/metal end bands and shortened rounded underside grooves. Twenty-eight newly mapped triangles use a dedicated 2K wrap atlas; existing repaired charts retain their UV placement. Main hull/glass maps and the undecided under-nose detail are unchanged.

Portable recipes document the bake and native export. Continue artwork in the canonical authoring workspace; this directory is a refreshed snapshot. The maintainer confirmed revision 3.0 finished and approved publication on 7 October 2026. Custom emissives remain a later update.
