# Patriot - Worn Paint

Current package: **0.1.0-beta.2**, artwork **3.0**, requiring **OpenReliant 0.8.1**. Redundant loadout colour variants have been removed; the engine generates green/red views from the original PNG material set.

Individual beta **0.1.0-beta.2**, artwork revision **3.0**. This pass adds six raised intake fins, readable metal on the forward radiators, aligned outer-engine panels and shortened underside grooves. The maintainer has approved v3 for publication.

Requires OpenReliant **0.8.1** and your own installed copy of StarLancer. Download the named player ZIP from [Patriot’s release](https://github.com/KonCyptFysh/OpenReliant-Art-Packs/releases/tag/patriot-v0.1.0-beta.2), then install `mods/96-patriot-worn-v1/` as described in [INSTALL.md](INSTALL.md).

The packed editable scene is `source/patriot_worn_audit_v3.blend`. Both native model variants and all three base/normal/ORM map families are included. Clone with Git LFS for the editable sources; the player ZIP contains real runtime files.

Original contributions are licensed under **CC-BY-NC-SA-4.0**; underlying game material is excluded. See [LICENSING.md](LICENSING.md). Custom emissives remain planned. The existing under-nose treatment is retained. [Known work](KNOWN_ISSUES.md) and [validation.json](validation.json) describe the remaining testing and artwork scope.

The optional mission 992 inspection scene and `tools/launch-patriot-test.sh` support local review.
