# Wolverine - Worn Paint

Individual beta **0.1.0-beta.1**, artwork revision **2.0**. Worn steel, warm markings and smoked-green glazing.

Requires OpenReliant **0.7.0** and your own installed copy of StarLancer. Download the player ZIP from [this ship’s release](https://github.com/KonCyptFysh/OpenReliant-Art-Packs/releases/tag/wolverine-v0.1.0-beta.1); install its `mods/60-wolverine-worn-v1` folder beside your game archives, then enable it under Game Options → Mods and restart. See [INSTALL.md](INSTALL.md).

The package includes this fighter only. Editable Blender scenes, maps, masks and selected recipes are in [source/](source/). Use Git LFS when cloning the editable artwork. The release ZIP contains real runtime files and does not need Git.

Texture refinements are ongoing. Custom emissives are a planned later update and their appearance is undecided. See [known work](KNOWN_ISSUES.md) and [validation scope](validation.json).
