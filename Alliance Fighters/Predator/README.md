# Predator - Worn Paint

Current package: **0.1.0-beta.2**, artwork **16.1**, requiring **OpenReliant 0.8.1**. Redundant loadout colour variants have been removed; the engine generates green/red views from the original PNG material set.

Individual beta **0.1.0-beta.2**, artwork revision **16.1**. Continuous wing fins, repaired surface detail and restrained paint markings.

Requires OpenReliant **0.8.1** and your own installed copy of StarLancer. Download the player ZIP from [this ship’s release](https://github.com/KonCyptFysh/OpenReliant-Art-Packs/releases/tag/predator-v0.1.0-beta.2); install its `mods/40-predator-worn-v14` folder beside your game archives, then enable it under Game Options → Mods and restart. See [INSTALL.md](INSTALL.md).

The package includes this fighter only. Editable Blender scenes, maps, masks and selected recipes are in [source/](source/). Use Git LFS when cloning the editable artwork. The release ZIP contains real runtime files and does not need Git.

Texture refinements are ongoing. Custom emissives are a planned later update and their appearance is undecided. See [known work](KNOWN_ISSUES.md) and [validation scope](validation.json).
