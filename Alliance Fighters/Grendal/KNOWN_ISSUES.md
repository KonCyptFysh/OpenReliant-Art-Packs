# Beta testing scope

Current compatibility target: official OpenReliant 0.8.1. See `compatibility-0.8.json` for this package-only update. All native models/missions and the PNG loadout-colour pipeline passed non-visual checks. No new 0.8.1 gameplay or GPU-rendering capture was performed. The earlier artwork and gameplay limitations below remain applicable.

- The user accepted artwork revision 1.1, including the current radiator treatment, for this beta. Further visual refinement remains possible.
- UV repairs affect the finest LOD; original lower-detail UVs need distance-transition review.
- Firing, damage, moving gun flaps, rear turret and loadout behavior need wider gameplay testing. Native records are preserved.
- Custom emissive maps are deferred. Runtime capture checks cover Linux with official OpenReliant 0.7.0; other platforms are untested.
