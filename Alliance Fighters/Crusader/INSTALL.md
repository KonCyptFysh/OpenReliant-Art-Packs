# Install Crusader - Worn Paint

Use OpenReliant 0.7.0 or later and your own StarLancer game data. Extract the player ZIP and copy `mods/99-crusader-worn-v1` into the game's `mods/` directory. Keep its files together in that flat folder. Enable Crusader - Worn Paint in the mod menu if it is disabled.

This pack replaces Crusader's main, training and loadout artwork. Remove its mod folder to uninstall. Avoid installing a second Crusader artwork pack at the same time.

## Optional quiet inspection scene on Linux

Copy `tools/launch-crusader-test.sh` beside `launch-openreliant.sh` and run `bash launch-crusader-test.sh`. Alternatively, set `OPENRELIANT_HOME` to that launcher directory. It opens mission 990 with Crusader ship 3, one ship, no enemies and sound disabled. Press 7 for external orbit; arrow keys rotate and Shift+Up/Down zoom.
