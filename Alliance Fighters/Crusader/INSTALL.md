# Install Crusader - Worn Paint

Use OpenReliant 0.8.1 or later and your own StarLancer game data. Extract the player ZIP and copy `mods/99-crusader-worn-v1` into the game's `mods/` directory. Keep its files together in that flat folder. Enable Crusader - Worn Paint in the mod menu if it is disabled.

This pack replaces Crusader's main, training and loadout artwork. Remove its mod folder to uninstall. Avoid installing a second Crusader artwork pack at the same time.

## Optional quiet inspection scene on Linux

For an upgrade, replace the old mod folder instead of merging into it. This removes obsolete `g`/`r` texture files. The engine generates loadout colours from the unprefixed PNG textures.

Developer inspection missions and launchers are retained in the local authoring workspace; use the named release ZIP for player installation.
